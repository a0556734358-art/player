# נגן אופליין (Android 13)

נגן שמע ווידאו שפועל כולו במכשיר, בלי הרשאת אינטרנט.

## יכולות
- סריקת קבצי שמע ווידאו מהמכשיר (MediaStore), עם חיפוש
- נגינה ברקע עם התראה וכפתורי שליטה (גם ממסך נעול ומכפתורי אוזניות)
- מהירות השמעה 0.75×–2× (נשמרת בין הפעלות)
- המשך מנקודת העצירה לכל קובץ (נשמר אוטומטית)
- דילוג 10 שניות אחורה/קדימה
- רשימות השמעה (יצירה, הוספה, הסרה, מחיקה)
- ממשק בעברית עם תמיכה ב-RTL, מצב כהה ו-Material You

## בנייה והרצה
1. התקן Android Studio (גרסה עדכנית, Koala או חדשה יותר).
2. File → Open ובחר את התיקייה `OfflinePlayer`. המתן ל-Gradle Sync
   (האינטרנט נדרש רק לבנייה, לא להרצת האפליקציה).
3. חבר מכשיר עם Android 13 (או אמולטור) והרץ: Run ▶
4. ל-APK להתקנה ידנית: Build → Build Bundle(s) / APK(s) → Build APK(s)

בהרצה הראשונה האפליקציה תבקש הרשאה לקרוא קבצי שמע/וידאו והרשאה להתראות.

## מבנה
- `PlaybackService.kt` – שירות הנגינה (Media3 ExoPlayer + MediaSession), שמירת נקודת עצירה
- `PlayerViewModel.kt` – חיבור לשירות, מצב הנגן, רשימות השמעה
- `MediaRepository.kt` – סריקת המכשיר
- `Stores.kt` – אחסון מקומי של נקודות עצירה ורשימות השמעה
- `PlayerApp.kt`, `NowPlayingScreen.kt` – ממשק (Jetpack Compose)
